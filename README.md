# Sales Analytics Dashboard

## Project Overview
Built an interactive Sales Analytics Dashboard using SQL and Power BI to analyze sales performance, profit trends, regional performance, and category-wise insights.

## Tools Used
- SQL (MySQL)
- Power BI
- DAX

## Key Features
- KPI Cards for Sales, Profit, Quantity, and Profit Margin
- Regional Sales Analysis
- Profit Analysis by Category
- Interactive Slicers and Filters
- Trend Analysis Over Time

## Business Insights
- West region generated highest sales
- Technology category produced highest profit
- Sales showed consistent growth over time
